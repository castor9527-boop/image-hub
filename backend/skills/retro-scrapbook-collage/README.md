# retro-scrapbook-collage

把日常照片转译成一张 **1086×1448 px、3:4 竖版**的复古 DIY 剪贴簿海报。

这个 skill 适合家庭相册、90/00 年代剪贴簿、照片贴纸拼贴，以及需要“人物居中、主体完整、物件可辨识”的日常照片改造。

## 核心效果

- 保留完整、可识别的人物和关键动作关系
- 让人物成为画面唯一主视觉，并保持水平居中
- 从原照片提取 5–8 个完整物件作为独立贴纸
- 使用少量星爆、圆点、三角形、短线、火花和几何形作为节奏装饰
- 使用 2–3 处与照片动作、场景和情绪相关的短文字
- 使用暖白哑光扫描纸、低清照片质感、轻微套印错位和不规则手工边缘

## 使用方式

在支持 Codex skill 的环境中调用：

```text
$retro-scrapbook-collage
```

然后附上一张照片，并说明希望保留的主体或动作关系。默认输出要求已经写入 `SKILL.md`，包括画布尺寸、构图安全区、物件完整性和质量门禁。

也可以直接描述具体关系，例如：

```text
使用 $retro-scrapbook-collage，把这张照片做成复古剪贴簿海报。
保留人物完整姿势和手里的物件，提取少量完整来源物件，人物居中，所有元素不要裁切。
```

## 构图规则

1. 人物必须位于画布中部，头部、鞋子、椅子和衣着轮廓保持完整。
2. 主体四周保留约 8–10% 的暖白安全边距。
3. 人物使用一圈单一、薄至中等厚度的不规则柠檬黄色手工描边。
4. 来源物件必须完整、可辨识、有浅色贴纸边缘，并全部位于画布内部。
5. 装饰围绕主体松散分布，不做网格、标本板、贴纸墙或碎片化素材页。
6. 文字必须短小、次要、可读，不覆盖人物和关键物件。

## 固定质量门禁

- 画布严格为 `1086×1448 px`、3:4 竖版
- 禁止正方形裁切、补边、拉伸或后期裁切修正比例
- 人物、动作关系和关键随身物必须完整
- 至少 5 个完整来源物件可辨识，且没有物件被画布边缘裁切
- 通用装饰控制在 6–10 个，并保持明显间隔
- 语义文字控制在 2–3 处
- 任一硬规则失败时，应重新生成，而不是用裁切、补边或拉伸补救

## 明确避免

- 不要把人物放在左下、右下或对角线位置
- 不要把人物做成小图放进完整矩形照片框
- 不要裁切人物的脸、手、脚、鞋、衣服或关键动作关系
- 不要把完整物件拆成纸角、标签、布纹、瓶盖或细碎零件
- 不要加入与原照片无关的动物、水果或随机可爱物件
- 不要使用品牌、日期、地点、署名、Logo、水印或长句
