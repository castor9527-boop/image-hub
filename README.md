# GGOO Image Hub

GGOO Image Hub 是 GGOO 主站下的 AI 图片创作工作台。它负责场景化需求整理、参考素材管理、图片生成和结果沉淀；账户、积分和消费记录由 GGOO 主站统一管理。

## 产品结构

工作台左上角的 GGOO 标识会跳转到主站：<https://ggoo.ai/chat>。

当前工作台包含以下入口：

- **Agent**：通过对话描述需求，完成图片方案和生成。
- **生图工作台**：保留自由 Prompt、生图、图生图和生成历史能力。
- **GGOO 场景生成**：面向不会写 Prompt 的用户，按业务场景、模板和视觉方向生成图片。
- **无限画布**：在画布中组织图片、文字、参考素材和生成节点。
- **我的素材**：统一管理用户上传的图片、生成结果、IP 形象、Logo 和品牌素材。
- **反推提示词**：从参考图片提取可编辑的图片描述。
- **动图生成**：上传或生成多帧图片并制作动图。
- **提示词广场**：独立导航入口，用于浏览和复用经过整理的提示词内容。

## 场景生成

场景生成保留 GGOO 原有的卡片式结构，并将业务用途收敛为四类视觉方向：

1. 营销视觉：门店活动、产品上新、节日促销等宣传内容。
2. 电商套图：商品主图、场景图、卖点图和参数图。
3. 内容配图：小红书、公众号、短视频封面等内容图片。
4. 品牌模板：沿用验证过的品牌版式和模板。

每个场景可以继续选择模板、视觉风格、画面比例和业务要求。比例规则和模板推荐比例由场景配置统一约束，避免生成尺寸与使用场景不匹配。

## 参考素材流程

用户上传参考图后，系统会先保存到素材库。只有用户选择“基于参考图继续创作”时，参考图才会参与图片生成。

参考图支持明确的角色标注：

- **Logo**：保持形状、颜色、比例和品牌位置。
- **产品名称图**：保留品牌文字、产品名称和拼写。
- **商品图**：保持外观、材质、结构和颜色。
- **宣传图**：参考构图层级、氛围和信息排列，不复制原图内容。
- **场景图**：参考背景、灯光和使用环境。
- **参数图**：只使用可确认的尺寸、规格和功能信息。

识别出的文字和图片事实会作为 Prompt 的事实锚点。Logo、产品名称等高准确性内容后续应优先通过真实素材叠加或后处理完成，不依赖图片模型自由重绘。

## 素材库

“我的素材”是统一素材入口，覆盖：

- 用户上传的参考图片
- 图片生成结果
- IP 形象和品牌 Logo
- 产品图片、包装图、宣传图和参数图
- 可供 Agent、场景生成和无限画布复用的素材

当前前端会保留浏览器本地缓存，并在后台同步到 GGOO 素材接口。素材归属目前使用临时工作区标识；正式上线时应替换为 GGOO 账户和会话身份。

## 账户与积分

工作台不再向用户展示本地 API、模型或上游服务配置。生产环境的账户信息、积分余额、消费记录和任务计费应统一由 GGOO 主站及中转服务提供。

当前“设置”入口仅在开发测试环境显示，用于临时配置本地 API 和调试数据。生产环境默认关闭：

```env
NEXT_PUBLIC_GGOO_SHOW_DEVELOPER_SETTINGS=false
```

## 技术结构

```text
image-hub/
├── frontend/       Next.js + React 前端工作台
├── backend/        Node.js 任务服务、WebSocket、SQLite 和图片接口
├── package.json    根目录启动与构建脚本
└── README.md       项目说明
```

前端负责工作流、Prompt 组成、参考图角色和本地交互；后端负责任务队列、任务状态、图片落盘、素材接口和上游请求代理。

生产架构目标：

```text
用户
  ↓
GGOO Image Hub 前端
  ↓
GGOO 中转服务 / 账户积分服务
  ↓
图片模型和视觉模型
```

上游服务名称、API 地址、API Key 和提示词来源不应暴露给普通用户。

## 本地运行

环境要求：

- Node.js 20 或更高版本
- npm 或 pnpm
- macOS、Linux 或 Windows

安装依赖：

```bash
npm run install:all
```

构建前端并启动集成服务：

```bash
npm run dev
```

默认访问地址：<http://127.0.0.1:3200/>

单独运行前端开发服务器：

```bash
npm run dev:frontend
```

单独运行后端服务：

```bash
npm run dev:backend
```

生产构建：

```bash
npm run build
NODE_ENV=production PORT=3200 npm start
```

## 环境变量

前端公开配置示例位于 `frontend/.env.example`：

```env
NEXT_PUBLIC_GGOO_MAIN_SITE_URL=https://ggoo.ai/chat
NEXT_PUBLIC_GGOO_SHOW_DEVELOPER_SETTINGS=false
```

后端运行参数示例位于 `backend/.env.example`。其中的 API、队列和存储参数仅用于本地开发或服务端部署，不应直接暴露到用户界面。

本地数据库、生成图片、素材文件、`node_modules`、构建产物和 `.env.local` 已加入 `.gitignore`，不会进入 GitHub 仓库。

## 验证命令
